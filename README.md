# MedRemind 💊
MedRemind is a modern Android application built with **Kotlin**, designed to help users track their medications and receive timely notifications.

## ✨ Features
- **User Auth:** Secure Login/Sign-up via Firebase.
- **Medication Tracking:** Add, edit, and manage medicine schedules.
- **Smart Alerts:** Real-time notifications for doses.
- **Sync:** Data is safely stored and synced using Firebase Realtime Database.

## 🛠 Tech Stack
- **Language:** Kotlin
- **UI:** XML with Material Design
- **Backend:** Firebase (Auth & Realtime Database)
